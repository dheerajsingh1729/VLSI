# VLSI Learning Journey

Welcome to my **VLSI Learning Journey** — a structured collection documenting my progress in **Digital Design, Verilog HDL, RTL Design, FPGA, and VLSI engineering**.

This repository contains my hands-on learning, Verilog programs, simulations, testbenches, RTL designs, FPGA implementations, hardware debugging experiments, and practical projects.

## 🎯 Objectives

- Build strong fundamentals in Digital Design and VLSI
- Learn **Verilog HDL** for RTL design
- Understand combinational and sequential logic
- Develop and verify RTL designs using testbenches
- Learn the **Xilinx Vivado** design flow
- Understand synthesis, implementation, and FPGA architecture
- Gain practical experience with hardware debugging
- Progress toward real-world **RTL/VLSI design projects**

## 📚 Learning Topics

### Digital Design

- Logic Gates
- Boolean Algebra
- Combinational Circuits
- Sequential Circuits
- Flip-Flops
- Counters
- Registers
- Multiplexers & Demultiplexers
- Encoders & Decoders
- Finite State Machines (FSM)

### Verilog HDL

- Verilog syntax and data types
- Modules and ports
- Continuous assignments
- Procedural blocks
- Blocking & non-blocking assignments
- `always` blocks
- Parameters
- Testbench development
- Synthesizable RTL coding

### FPGA & Vivado

- Xilinx Vivado Design Suite
- RTL simulation
- Synthesis
- Implementation
- Design constraints
- IP Integrator
- FPGA architecture
- Bitstream generation
- FPGA programming

### Hardware Debugging

- Integrated Logic Analyzer (ILA)
- Virtual Input/Output (VIO)
- Hardware verification
- FPGA debugging
